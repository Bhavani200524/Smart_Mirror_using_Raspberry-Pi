# Smart_Mirror_using_Raspberry-Pi
A Raspberry Pi based Smart Mirror project that displays useful real-time information such as time, date, weather updates, and news using Python and IoT technologies.

## Overview
The Smart Mirror is an IoT-based project developed using Raspberry Pi and Python. It displays useful real-time information 
such as time, date, weather updates, and news while functioning as a regular mirror.

This project demonstrates the application of embedded systems and IoT technologies in smart home automation.

## Features
- Real-time Clock and Date
- Weather Updates
- News Display
- Wi-Fi Connectivity
- Interactive Information Display
- Smart Home Application

## Technologies Used
- Raspberry Pi
- Python
- IoT Concepts
- Raspberry Pi OS

## Hardware Requirements
- Raspberry Pi
- Monitor/Display
- Two-way Mirror
- HDMI Cable
- Power Supply

## Software Requirements
- Python
- Raspberry Pi OS

## Working Principle
The Raspberry Pi collects real-time information and displays it on a monitor placed behind a two-way mirror.
Users can view useful information while using it as a normal mirror.
